02 · ONE ORDER, STEP BY STEP

FIND SHOPS

  1. Buyer says "hi"; agent replies with a one-time 📍 link
  2. Buyer taps Allow: GPS goes to the agent
  3. ShopSearch(lat, lng, live) → Store Locator
  4. ShopList: nearby shops + their agents

GET QUOTES

  1. QuoteRequest to every Merchant Agent at once
  2. QuoteList: price per item, fees, open now

CHECK

  1. CheckQuotes → Trust Agent
  2. Verdict: hidden-fee shop blocked, options 1–3
  3. Buyer replies 1 / 2 / 3 or haan

ORDER

  1. OrderRequest → the chosen shops' agents
  2. Owner taps YES (60 s)
  3. OrderResult → Verified Receipt in chat

PAY AGENT CHARGE

  1. RequestPayment to the shop's agent
  2. Shop agent sends FET on testnet → CommitPayment
  3. Verified on-chain → CompletePayment. Buyer pays ₹0 extra
