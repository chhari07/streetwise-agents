STREETWISE: SAMPLE ORDER CHATS
==============================
Seven orders, each with its own items (no item is repeated across orders).
Each chat below is a real test run (18 Oct 2026): live map shops, demo prices.
Shop names, prices and the blocked shop can change on every run.

BEFORE YOU START
----------------
1. In this folder:  source .venv/bin/activate  then  python run_all.py
2. Open the "Agent inspector" link from the log -> Connect -> Mailbox.
3. Open http://localhost:8090 (shop owner YES / NO) and http://localhost:8090/map (live map).
4. In ASI:One, chat with:
   agent1qfv4qg39ul92cqj29degg2zs36gkr04ga59kwd85eqr0xlmedsr07zveljw
5. Type the BUYER lines below. After you pick an option, tap YES on the
   owner screen within 60 seconds (in these tests the owner said YES automatically).

TIPS
----
- Reply 1 / 2 / 3 to pick an option. "haan" always means option 1.
- If an order shows only option 1, reply 1 or haan.
- No "near <area>"? The agent asks "Aap kahan hain?". Reply with an area or pincode.
- Don't use an item word in the area name (e.g. "Salt Lake" adds salt).
